# 3.4 方案决策：针对几何碎片拒绝简化，不能声称修复 86% 漏检

记录于本地诊断之后、模型重推理代码和部署之前。原始证据、单人视觉标注及复算见 `evidence/diagnosis/`。

## 已有证据改变了假设

- 280 次初始化的 240 次 missing_model_roi 确实全是目标色分块阳性数为 0；没有把“不连通/并集过大”混入该数字。4,480 个实际分块均由源 PNG 重建并通过逐项像素 SHA256。
- 红色全部 102 张源图逐张审查：8 张明确可见红球、1 张 7 像素边缘片不确定、93 张不见红球。8 张可见图全部有旧模型区域，但最终 bbox 仅 1 张；另外 7 张在无类别碎片＋逐片识别中丢失。94 个 missing 全为 93 张不可见＋1 张不确定，不能称 94 次红球漏检。
- 8 个红球可见框都至少完整位于一个 256×192 重叠块，且这些完整块中至少一个被九格正确判红。5 个完整球体约 29–42 px 宽、38–48 px 高；其余 3 个首先被原图边界裁断。证据不支持“分块把红球切半，所以认不出”为主要根因。
- 紫/蓝按预先规则选出的 53 张诊断样本也没有明确可见目标却 missing 的例子；它们经过输出类别分层抽样，不能估计全体召回率。
- 与 3.1 同时改变了完整画面/分块、JSON/简答、128/12 token、默认图像切片/固定 max_slice_nums=1 及采样机位，不能把 3.1 开发集 100% 与飞行中的全部无目标帧直接对比。

## 两个低改动候选

1. 保留已在红色可见帧给出 8/8 区域的重叠分块，只将“8 碎片识别”替换为单一大 ROI bbox 回归。可以隔离第二段损失，保留第一段已知行为，但仍需 16 个输入项，单框坐标能力尚未验证。
2. **先离线探测的简化候选**：完整原始 RGB，完全复用存档 3.1 提示词/schema，获取目标色与 left/center/right；将该三分区扩为宽度 2/3、全高的一个 ROI，再调用一次九格直接输出该 ROI 中指定色可见球体 bbox。保留原图坐标变换和所有原回答，不使用碎片分割、HSV、YOLO 或世界真值。

选 2 做有限离线探测，因为它直接去掉已证实丢失 7/8 红色有效区域的碎片阶段，且可降低输入数量。**不是认定完整图能补回 94 个“漏检”**：目标未入镜时不能靠识别器凭空产生目标。若 3.1 粗区域/直接 bbox 不可靠，立即停止，不能再加分块规则、语义 fallback 或修改飞行搜索。

## 探测协议与停止门（执行前冻结）

- 只用旧红色三局源 PNG：全部 8 张可见＋1 张不确定，另从每局不可见帧等距选 5 张，合计 24 张。同一图像比较旧区域、旧最终框及新两步结果；这是开发诊断，不是独立正式识别验收。
- 第一问使用存档 3.1 原提示词，严格 color+region schema，max_new_tokens=128，默认图像切片。明确审计真实 processor 图片数，单模型、单进程，不连接 ROS、不发布控制、不改部署。不得将假定输出当作提升。
- 目标色唯一且 region 合法才调用第二问。ROI：left=[0,0,2W/3,H]、center=[W/6,0,5W/6,H]、right=[W/3,0,W,H]；不按人工 bbox 修正 region。第二问只输出指定色可见球体的归一化 [0,1000] bbox 或 null，排除小车；严格 schema/范围/非空框检查，转换回原图。无第三问、无 CV 细化补救。
- 只有目标可见 8/8 被第一问识别、至少 6/8 最终框达到 IoU≥0.5 且中心误差≤max(8 px, 可见球体对角线20%)、15 个不可见负样本均无有效目标框时，才考虑接入。另给完整/原图截断分层结果；单人手工 bbox 约 ±4 px，临界项要报告。
- 若通过以上门，再以已有连续真实帧做 CSRT 回放，验证结果返回时仍能追到当前帧；不改帧龄、语义龄或伺服门。回放不支持即停止，不飞。
- 只有离线完整链支持时才写隔离候选并测红色 3 局；仍须同一模型、原封存飞行结构、安全边界、优化 1/2。红色未进入冲刺/仍卡 50 s 或未达到物理指标则停止，不扩三色。全部对照沿用原采用门，不能凭识别率或一次冲刺宣布采用。

全类别和 3.1 蓝色缺口不变；旧 3.2/3.3 数据和部署不变。总预算 2 天，负结果同样交付。

## 探测后的决定

24 帧真实重推理完整结束：8/8 可见红球第一问非空、8/8 有最终框，0/8 满足已冻结几何门；最大 IoU 0.0539、中心误差44.0–238.5px。大ROI均含目标，实际裁剪/传图/坐标换算核对通过。因此本候选不采用，按协议不进入跟踪回放或新飞行；不增加提示/分块补救，也不改封存伺服。完整数据、负例unknown回答和范围见 REPORT.md。
