# 第二次实施源码

这是 2026-10-25 重新接手后的独立候选。首轮 `source/`、`staging/` 和旧证据保留作审计，不能混用部署。

识别链：sensor1 RGB → 同一 mission_once/九格模型实例 → 16 个均匀重叠视图的语义结果 → 局部阳性区域并集 → 无类别图分割 → 九格识别各局部区域的实际像素 → CSRT 时序回放/实时跟踪 → 独立 MultimodalTargetTracker → 原 VisualServo。

- 九格负责气球类别、颜色和初始区域；不读 YOLO、HSV、UE 坐标或判定结果。YOLO 在气球门控期间暂停。其他阶段仍为旧识别链，不能据此申请全类别独立识别完整 10 分。
- 命令生成辅助函数的 AST 与封存入口一致，模型只加载一次，命令和图像调用共用同一互斥锁。实际 processor 输入处校验每个样本恰有一张 PIL 图像。
- 无九格局部区域、区域过大/分离、时序断裂和跟踪失败均不猜框。通用图分割没有颜色/目标类别；区域原像素之外置黑，再由九格赋类，只有其确认的同色区域可初始化。`refinement.py` 是旧 GrabCut 探测保留件，当前 runtime 不调用。
- 模型结果年龄从相机帧采集开始；不会在推理结束时重置。语义确认只更新观察时间，不能把延迟框覆盖当前几何。
- UI 在主线程显示实际跟踪帧，记录真实窗口截图、源图 SHA256、模型原回答、会话及决策 ID、像素消费和执行控制。

部署内容的原始字节 MD5 在 [manifest.json](manifest.json)。`baseline_*.py/cpp` 为原始字节的备份副本，不是需要复制覆盖的开发文件。入口和 BT 候选由 [patch_v2_sources.py](../patches/patch_v2_sources.py)从已锁定基线生成。部署/回滚使用 [switch_condition_v2.sh](../tools/switch_condition_v2.sh)，须提供真实备份目录并在已经占用的空闲服务器执行；脚本检查无正式锁、PX4 解除武装，精确停止模型，串行编译并校验实际二进制。

验证状态以最终 3.2/3.3 报告为准。开发真实帧和接口单测均不能代替实飞演示或回归。
