# 任务 3.1 中期报告

日期：2026-10-21（北京时间）

## 结论

FM9G4B-V 的图像输入、离线推理、严格 JSON 校验和时延统计流程已跑通。当前证据支持把 3.1 标记为“阶段评测完成、正式验收未完成”。原因是原视角蓝色目标只有 14 张可独立辨认帧，且新增补录没有形成满足验收口径的独立固定相机测试集。

## 已完成

- 模型使用 `/home/ubuntu/model/FM9G4B-V`，在 NVIDIA L40/BF16 上运行。
- 评测器固定完整 640×480 RGB 图像、固定提示词、一次预热、同步 GPU 计时。
- 原视角 60 帧完成哈希锁定和离线评测，红/蓝/紫各 20 张。
- 相机偏移诊断额外采集 20 帧并保存采集元数据、帧哈希和原始预测。
- 结果复核脚本可在不加载模型的情况下重算 schema、命中率、颜色集合准确率和 P50/P95。

## 风险与限制

- 标签是暂定视觉复核，尚无第二名复核者确认；旧结果复核时曾接触模型输出，因此不是完全盲标。
- `collection_group` 表示采集条件，不代表画面只有该颜色；画面中可能同时出现红、蓝、紫目标。
- 当前没有独立 region 真值，不能声称位置准确率。
- 相邻帧高度相关，不能直接解释为 60 次独立试验。
- 相机偏移采集结束时只记录“已发送恢复请求”，没有独立验证恢复后的画面。
- 本报告没有验证 3.2 的窗口显示、目标选择参与控制和 3 局实飞，也没有验证 3.3 回归。
