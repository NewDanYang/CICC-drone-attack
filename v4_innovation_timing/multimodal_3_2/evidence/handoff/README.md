# 3.1 中期报告与可复现工具

本目录整理 FM9G4B-V 任务 3.1 的离线评测工具和中期结论。工具只做离线图像推理与结果审计，不发布 ROS 消息，也不修改飞控或击球控制。

## 当前结论

- 原视角开发集：红 20 帧、蓝 20 帧、紫 20 帧；哈希校验通过。
- 原视角人工复核：红可见 20/20，蓝可见 14/20（另 1 帧不确定、5 帧不可见），紫可见 20/20。
- 固定提示词评测：红 20/20，蓝 4/14，紫 20/20；颜色集合准确率 49/59 = 83.05%；结构非法 2；全局 P50/P95 为 2.386/2.627 秒。
- 相机偏移诊断集：蓝可见 18/18，但不可见负样本误报 2/2；该组改变了取图条件，不能与固定相机结果合并为正式验收准确率。
- 后续补录批次曾被标为 20 张蓝色标签，但模型实际命中 6/20，且标签仍属于补录诊断，不能替代独立测试集。

因此 3.1 的流程已经跑通，证据已留档，但正式验收仍需固定相机条件下的独立采样、第二人标注复核，以及蓝色至少 20 张独立可辨认目标帧。3.2/3.3 不在本目录的验收范围内。

## 工具

- `tools/evaluate_3_1_v2.py`：固定提示词、严格 JSON schema、哈希锁定的离线评测器。
- `tools/collect_blue_shift.py`：记录相机临时偏移、采集 20 帧并在结束时发送恢复请求的诊断脚本。
- `tools/verify_latest_results.py`：不加载模型，重算预测解析、命中率、颜色集合准确率和 P50/P95。
- `tools/check_evaluator.py`：检查评测器和标签的基本完整性。
- `tools/build_audit.py`：生成交接审计包。
- `verification_latest.json`：最近两轮结果的审计状态；`PASS` 表示计算与哈希可复核，不表示标注已经独立确认。

## 服务器运行

```bash
/opt/conda/envs/demo/bin/python3 /root/task3_1_tools/evaluate_3_1_v2.py --check
/opt/conda/envs/demo/bin/python3 -u /root/task3_1_tools/evaluate_3_1_v2.py --run --smoke
/opt/conda/envs/demo/bin/python3 -u /root/task3_1_tools/evaluate_3_1_v2.py --run
```

运行完整评测前，确认 GPU 上没有第二份 FM9G4B-V 实例。评测器默认读取 `/home/ubuntu/multimodal_task3/eval_frames_gated` 和同目录下的 `labels.jsonl`；新测试集必须使用自己的数据目录和标签文件，不能覆盖原始审核图或复用旧哈希。

正式补样时，预先冻结提示词、模型版本、相机外参、采样规则和标注规则；保留每帧图像哈希、ROS 图像 header、采集时间和独立可见性标签。相邻视频帧不能当成独立试验次数。

## 交接边界

当前结果是开发集/诊断集，不是 3.1 正式验收结论。没有独立 region 真值，因此不报告位置准确率；没有 3 局击球记录，因此不报告 3.2；没有接入前后可比回归，因此不报告 3.3。
