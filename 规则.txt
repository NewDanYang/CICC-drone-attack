1. 大赛简介
大赛由中国指挥与控制学会主办，是国内无人系统与具身智能领域的权威赛事。

1.1 九格大模型语义解析为必选项
各赛道都遵循同一条主线——"自然语言指令 → 九格大模型解析 → 机器人自主执行"，其中九格大模型语义解析为必选项。就是你用自然语言下指令，大模型负责理解与拆解，机器人再自主完成执行。这要求队伍基于大模型打通从指令理解到任务执行的全链路，也是对具身智能前沿能力的真正检验。
需要特别强调：所有赛道一律不得更换组委会指定的九格大模型，违者按各赛道规则取消成绩。
1.2 双阶段成长路径：线上练兵到线下实战
大赛采用线上仿真预赛 + 线下实机决赛两阶段赛制：2026年10月举行全国线上仿真预赛（直播赛），按成绩择优晋级；12月在深圳进行线下实机决赛。即使是第一次参赛的队伍，也能走完从算法开发到实机验证的完整参赛周期，获得系统性成长。
1.3 零硬件门槛起步：官方提供全套资源
无需采购硬件、无需自行搭建环境，官方已备齐从开发到参赛的全套资源：
- 开发资源：各赛道提供GitHub使用手册、官方demo算法，仿真基础环境提前部署，开箱即用。
- 培训答疑：提供教学视频与线上线下培训，QQ社群全程答疑。
- 算力支持：每队免费赠送一次50元线上仿真算力额度，用完后可自行充值。
- 硬件统一：机器人硬件由组委会统一提供，零基础也能快速上手。
设备要求：线上仿真以共享屏幕方式演示任务，请保证网络稳定、无明显延迟；线下实机需自备个人笔记本、便携显示器、DP/HDMI线、键盘、鼠标、拓展坞等开发设备。
1.4 支持一队多赛道
赛道数量不限，一支队伍可以同时报名多个赛道。五大赛道覆盖机械臂、四足机器狗、无人机、人形机器人、轮式人形机器人，你可以按团队的技术储备灵活组合，把优势发挥到最大。

大赛设立一、二、三等奖，由中国指挥与控制学会颁发权威证书。官方媒体矩阵覆盖公众号、小红书、抖音、B站、视频号（搜索「TCEI具智非凡」），为优秀队伍提供曝光机会。大赛不收参赛费，决赛期间的交通食宿，组委会会视情况给予补助。

4. 参赛指南
4.1 通用参赛流程
无论你参加哪个赛道，整体参赛流程都遵循以下步骤：
第一步：官网报名与组队
1. 组建队伍：根据团队技术背景选择合适的赛道、确定参赛成员（每队≤10人，指导教师≤2人），先完成组队。
2. 扫码报名：找到官网「报名参赛」（https://tcei.c2.org.cn/competition/apply）文字下方的二维码，使用手机扫码。
3. 填写表单：扫码后进入WPS表单，填写参赛人员信息并提交，即报名成功。
4. 修改/撤回：表单支持「修改填写记录」和「撤回提交」，填写有误可自行更正。
[图片]
5. 了解赛道规则：阅读赛道规则（https://tcei.c2.org.cn/competition/tracks）。
[图片]
6. 进入赛道规则页，可获取开发资源与比赛入口。以四足机器狗赛道为例：页面正文是完整的赛道规则文档，左上角有两个核心入口——「Github资料下载」（内含使用手册）和「预赛比赛入口」。
[图片]
7. 点击「预赛比赛入口」，会自动跳转到算力自由平台的对应赛道镜像仓库页面。
[图片]
- 左侧：赛道说明和使用手册（内容与Github下载包一致）
- 右侧：当前赛道镜像的 GPU 配置与价格
第二步：注册算力平台
仿真赛将统一算力上限，于算力自由平台进行，以保证赛事公平。以下是注册并进入镜像环境的完整操作流程。
1. 进入算力自由官网：https://www.gpufree.cn/home
2. 点击页面右上角「注册 / 登录」完成注册，完成后我们才会为你发放算力额度。
关键约束：每个队伍仅发放一次50元算力，注册完预计1-3天内到账，以WPS表单报名中提交的联系人手机号为准；因此算力自由注册的手机号必须与报名表单完全一致，否则额度无法到账。额度用完后可自行充值。
常见问题：已有选手反馈注册手机号和报名手机号不一致，导致50元算力无法到账。请务必确认两个平台使用同一手机号注册！
第三步：进入镜像环境
1. 注册后点击「镜像仓库」。
[图片]
2. 类别中选择 "TCEI"，或直接访问：https://www.gpufree.cn/images?tag=TCEI
3. 点击对应的参赛赛道。
[图片]
4. 点击「使用手册」查看运行方法。
5. 点击「快速创建」进入镜像环境。
赛事相比去年的最大变化：本次竞赛环境已预先完成全部依赖部署，实现开箱即用。选手无需进行任何环境配置，可立即开始工作。任何环节遇到技术问题，可联系QQ群管理员进行答疑。
第四步：参加线上仿真赛流程
赛前排队：仿真赛暂定采用线上腾讯会议共享屏幕形式。组委会会提前排好每支队伍的参赛顺序并在群里公布，比赛当天工作人员会在群里通知即将参赛的队伍做好准备，请务必提前启动镜像。特别提醒：比赛当天算力紧张、容易抢不到显卡，请提前 1–3 天就把镜像开通，当天直接进环境调试，不要临时开通。
共享屏幕：工作人员叫到对应的队伍名称和单位时，请申请共享屏幕。共享画面应为已启动的镜像仓库，尽量不要在共享屏幕后才启动镜像，以减少等待时间。
开始计时：提前打开终端窗口与提示词文本，复制好第一个提示词并粘贴到终端。工作人员询问是否准备好，选手回答准备好后，工作人员宣布开始并同时计时；此时选手按回车发送已粘贴的提示词指令，开始任务。
演示与答辩：任务演示完毕后，选手回答演示完毕，工作人员判断是否完成任务后结束计时，并告知本次演示时长和分数。如工作人员提出异议或问题，选手需回答；工作人员会询问是否使用九格多模态，若使用了，请在演示结束后准备好多模态PPT并提交相关代码包备查。
至此一支队伍的线上仿真演示就结束了，我们按分数排名；分数相同时，用时最短的队伍排名靠前。
每支队伍有两次演示机会，第一次未完成的可申请第二次，我们取两次演示中成绩较高的一次作为最终排名。晋级名单公布后，请及时告知所在单位，做好前往深圳参加线下培训与决赛的准备；决赛期间请妥善保管硬件设备，一旦损坏会影响比赛任务完成。
代码包提交：所有参赛队伍均须向赛事工作组提交代码包，压缩包命名格式为「赛道_队伍名称_单位_联系方式」，内容应包含：源代码、技术报告、答辩 PPT。
4.2 九格多模态大模型
Q：比赛使用的是本地模型吗，笔记本上能运行吗？
A：比赛使用的是本地的九格4B大模型，推理需要的显存大致在8-12G，一般笔记本电脑显存是8G，建议不要笔记本电脑上运行。
Q：官方提供的demo里面的九格大模型和加分项有什么区别？
A：官方提供的demo里面框架是YOLO识别目标位姿，传给大模型继续后续操作，但是加分项是不需要其他框架做目标识别，只能由九格大模型去完成。
Q：加分项怎么做？
A：九格大模型里面是有BBOX的（输⼊是⼀张图像和⼀条明确指令，输出是⼀个⽬标的边界框），但是demo的九格大模型BBOX偏差特别大，需要选手优化这一方面，具体微调方法请看《九格大模型的量化与微调》。

5.3 平台与环境使用
Q：线上仿真平台对电脑配置有什么要求？
A：无要求。仿真在云端算力平台运行，本地电脑只需浏览器和稳定网络即可。
Q：仿真平台使用问题联系谁？
A：群内联系技术人员或平台客服。
Q：推荐学习哪些技术栈或工具？
A：常用技术栈包括 C++、Python、ROS1、ROS2、YOLO、OpenCV、深度学习框架等。
Q：能否在本地电脑部署开发环境？
A：不支持在本地部署环境。为统一算力上限、保证比赛公平，所有开发与比赛都在算力自由平台的官方镜像环境中进行。
Q：镜像仓库的 Ubuntu 系统能否更改？
A：镜像仓库的 Ubuntu 系统不能更改，官方已预装并配置好基础环境，不可自行重装或替换系统；但选手可在该环境内安装软件、优化自己的算法。
Q：官方 demo 可以直接用于参赛吗？
A：每个赛道都提供基础 demo，大家需要在这个基础上自己进行优化，不建议直接使用官方 demo 参赛。
Q：在镜像里无法粘贴文字或代码怎么办？
A：无法在镜像仓库粘贴时，需要在浏览器中打开（允许）剪贴板粘贴权限，之后即可正常粘贴。
Q：镜像仓库提示显卡（卡资源）不足怎么办？
A：可以先自己克隆实例。「克隆实例」功能可复制一个实例的系统盘，并粘贴到一个新创建的实例。通常是当前机器上没有卡了，可以通过「克隆实例」把系统环境迁移到其他有卡的机器上。
Q：算力自由平台支持一个账号多人同时登录吗？
A：可以，一个账号支持多人登录。
Q：可以在镜像的 Ubuntu 里安装 QQ、微信吗？
A：Ubuntu 是支持的，但是不建议在服务器上登录相关账号。
Q：系统盘可以扩容吗？
A：系统盘不能扩容。空间不足时，帮助文档里有清理系统盘的方法：https://www.gpufree.cn/docs/guide/data_disk/clear_sysdisk.html
Q：第一次启动 Isaac Sim 为什么很慢？
A：第一次启动 Isaac Sim 需要加载资产，所以比较慢，属于正常现象，后续启动会加快。
Q：镜像里如何使用中文输入法？
A：可以安装搜狗输入法的 Linux 版本。
Q：线上培训在哪里通知？
A：线上培训会在官方 QQ 群内通知。
Q：算力自由平台的使用文档在哪里？
A：算力自由平台的所有使用文档见：https://www.gpufree.cn/docs/；常见问题文档见：https://www.gpufree.cn/docs/guide/instance/qa.html，能解决平时大部分问题。
5.4 九格大模型与加分规则
Q：提示词指令从哪里获取？可以自己编写吗？
A：每个赛道输入的指令都在官网规则页，必须使用组委会指定的提示词指令。所有提示词只能一步步输入执行，不能用脚本一键执行完毕。
Q：官方预赛 demo 为什么用 YOLO，而不是用九格做目标检测？
A：官方 demo 用 YOLO 是为了让大家快速跑通流程；但九格多模态做目标识别是加分项，这些都需要你们去应用，且可以确定是能够实现的。
Q：九格大模型可以和 YOLO 混合完成目标识别吗？有额外加分吗？还是必须完全不用 YOLO？
A：混合使用不算额外加分，需要使用九格多模态独立完成目标识别，具体请看官网规则。可以用 YOLO 辅助，但使用 YOLO 无法拿到加分项。
Q：九格大模型的加分如何判定？是看日志还是接口调用记录？
A：组委会会复核相关代码，不只是看接口调用记录或日志。
Q：用大模型做目标识别，只识别一个种类的目标就能得分，还是所有目标都要识别？
A：以比赛规则为准，需要全部识别。障碍物、气球、方形障碍、起降标识、烟雾弹等都需要识别，不是只识别一个就得分。
Q：能否先用大模型从完整相机图像输出目标类别及初始检测框，再使用目标跟踪器进行跟踪？
A：可以。
Q：九格不就是做目标识别吗？没有 YOLO 怎么知道位置和深度？
A：目标位置通过视觉识别，深度由摄像头（深度相机）给出。
Q：可以对九格大模型做 LoRA、QLoRA 或量化微调吗？
A：允许。在不更换 FM9G4B-V 模型架构的情况下，可按照官方《九格大模型的量化和训练》文档进行 LoRA、QLoRA 或量化。
Q：可以自己创建或修改整体算法和软件架构吗？
A：不建议选手修改比赛整体架构；可以针对某些决策等算法进行修改或优化。
Q：可以调低 Isaac Sim 的渲染帧率或步长，让仿真时间和真实时间对齐吗？
A：不能修改。即使把步长调到与真实时间对齐，也不允许修改。
5.5 机械臂赛道
Q：是否允许修改控制器和规划代码？是否要求提交数据、权重和训练日志？
A：可以修改控制器和规划代码；需要提交代码。
Q：官方提供的 Python、C++、launch 和 ROS Demo 是否都允许修改或新增节点？
A：允许。
Q：可以用 YOLO 辅助识别吗？
A：可以使用 YOLO 辅助，但使用 YOLO 拿不到加分项。
Q：是否允许修改机械臂路径规划、抓取姿态、运动时间、超时和失败恢复逻辑？
A：可以修改和优化这些逻辑，但不允许修改 Isaac Sim 仿真时钟速度。
Q：是否允许九格与官方 YOLO 协同识别，只要九格确实参与指令解析和目标选择？
A：可以。
Q：是否禁止修改场景中的相机位置、物体位置、物理属性和碰撞参数？
A：禁止修改。
Q：能否导出不同官方场景批次的原始相机图？这些图能否由独立人员标注真实 bbox 后用于 LoRA/QLoRA？是否有官方数据集或标注？
A：允许导出官方场景的原始相机图；可以由独立人员标注 bbox 后用于 LoRA/QLoRA；官方不提供数据集，需要自己训练数据集。
Q：只用 YOLO 提供候选框（告诉系统哪些区域可能有物体），语义理解和候选框识别都靠九格模型，符合加分要求吗？
A：不符合，只有九格多模态做目标识别才加分。
5.6 四足机器狗赛道
Q：赛道场景有压缩干粮物资吗？
A：暂时没有压缩干粮物资。
Q：「四类物资—存储点—赛场坐标表」在哪里查看？
A：机器狗赛道的物资在仿真中可以看见，没有坐标表。
Q：导航轨迹优化是在 Rviz 上调整，还是优化命令的自然语言？
A：轨迹、导航、自然语言指令都需要优化，导航通过自然语言去跑。
Q：规则中「开始移动后不得触碰或遥控」，是否意味着开始移动后整个比赛过程中都不能再发送新的控制指令或任务指令？
A：任务开始后只能发送指定的提示词，不能发送其他控制指令或任务指令。
5.7 无人机与救援赛道
Q（救援赛）：无人机下视视角相机的 RGB 图是否可以作为 YOLO 或大模型识别救援人员的输入？还是只能用 2D 栅格地图识别？
A：可以。二者都是为了提高识别准确度，官方 demo 给出的是 2D 栅格地图方法（第二种），您可以自己调整。
Q（救援赛）：输入一条特定指令，大模型却执行多个任务，这属于 bug 吗？还是需要进行开发微调？
A：这是大模型语义理解出现偏差，需要自行去调整（微调）。
Q（打击赛）：出现穿模（碰撞）是只扣一次分，还是穿模一次扣一次分？
A：碰到都会扣分，但只扣一次；只要碰撞一次就扣 10 分，扣完之后后面再碰就不扣了。
5.8 奖项与证书相关
Q：比赛设置哪些奖项？
A：大赛本着"公平、公正、公开"的原则，评选出一等奖、二等奖、三等奖、技术创新奖、优秀指导教师奖若干。
